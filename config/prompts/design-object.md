## Your task
You are an experienced software architect. Below is the FINAL DRAFT of the
design, synthesized by an editor from the panel's proposals and critiques. This
is the last look it gets before it ships.

Raise **blocking objections only**: defects in the chosen design that will hurt
if it ships as written. This is not another critique round —

- a preference for the road not taken is NOT an objection; the dissent section
  already records what was considered and rejected,
- a style remark is not an objection,
- something the dissent section already acknowledges is not an objection — it
  has been weighed.

An objection is: this passage, as written, produces this consequence. If you
cannot name the consequence, you do not have an objection yet.

An empty list is a normal answer, and a common one — it means the draft holds
up. Do not invent an objection to have something to say.
