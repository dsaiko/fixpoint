# Gemini 3.7 Flash -- DISQUALIFIED 2026-08-19, three routes, three distinct
# root causes, all measured. Left listed so nobody re-derives any of them.
#
# 1. agy (Antigravity, its native CLI): headless agy denies read_file without
#    --dangerously-skip-permissions, so the agent must declare can_edit: true,
#    and validation refuses a writable agent in roles.review. --mode takes only
#    accept-edits or plan; --sandbox restricts the terminal, not writes. The CLI
#    offers no way to be a reviewer.
#
# 2. OpenRouter + the claude harness (the grok-4.6 route): every call returns an
#    EMPTY `result` field with tokens billed. OpenRouter's Anthropic translation
#    emits gemini responses as [text, thinking(signature-only)] -- text FIRST,
#    trailing signature block LAST -- and the harness reads its reply from the
#    text after the last thinking block. grok works there only because its text
#    arrives last ([thinking, redacted_thinking, text], verified side by side).
#    Reasoning "is mandatory for this endpoint and cannot be disabled", and
#    Vertex returns the same block order as AI Studio, so there is no provider
#    that avoids it.
#
# 3. OpenRouter + the codex harness (the codex@ route below, built for this):
#    short sessions work -- tool calls, file reads, correct replies. Every real
#    review session dies the same way, 5/5 across the code and design targets:
#    Google's content filter truncates the stream mid-response
#    ("content_filter"), codex reconnects by resending the conversation, which
#    now ends with the partial assistant turn, and Gemini rejects it -- 400
#    "Requests ending with a model turn are not supported." The filter is
#    Google's, the resend is codex's protocol, and the rejection is Gemini's
#    API rule; none of the three is ours to change. Only Google providers serve
#    this model on OpenRouter, so there is no filter-free upstream either.
#
# 4. The same codex route pinned to Vertex ("Google" on OpenRouter, vs "Google
#    AI Studio"): identical chain, content_filter then the model-turn 400. The
#    filter is Google's on both providers. Pinning knowledge worth keeping even
#    though it did not save this model: OpenRouter accepts a provider suffix on
#    the slug -- `google/gemini-3.7-flash:vertex` is a valid model id --
#    while `model@provider` is not. The suffix rides through any harness, since
#    it is just a model name.
#
# The zero rows in results.csv are those runs. The bench's own words: a
# model that cannot finish a run cannot hold a seat. Retry when any of the
# three parties changes behavior.
